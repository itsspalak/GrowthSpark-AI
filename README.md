# GrowthSpark AI — Campaign Lab

**Assessment project:** AI Growth & Automation Associate — Task 1: AI Skills & Prompt Engineering  
**Domain:** Technology / Digital Marketing  
**Format:** Responsive browser-based prototype

## What it does
GrowthSpark AI helps a growth marketer turn a product, audience, goal, channel, budget, duration, and customer insight into a structured campaign plan. The prototype provides:

- Campaign angles and messaging directions
- Three experiment ideas
- Suggested KPIs
- A practical execution plan
- Copy and download options for the generated plan
- Dark, responsive interface

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a current browser (Chrome, Edge, Firefox, or Safari).
3. Enter a sample product and audience, select a goal and channel, and click the generate action.
4. Review the campaign angles, experiments, KPIs, and execution plan.
5. Try the copy/download controls.

No installation, API key, server, or account is required.

## Important transparency note
This is a functional front-end prototype. The current campaign output is produced by predefined JavaScript rules and templates; it does **not** call a live LLM, external API, analytics platform, or advertising account. AI assistance was used during ideation, specification, interface/code drafting, and documentation. Do not describe this version as a live AI integration. A production version could connect an LLM through a secure backend and validate suggestions against real campaign data.
